# Marvel Legendary Game Setup

This context defines the language used to describe a playable setup using the Marvel Legendary First Edition core box and its expansions.

## Game scope

**Marvel Legendary**:
The Upper Deck deck-building game about Marvel characters. It is distinct from other games in the broader Legendary series.

**Core box**:
The base product for a particular Marvel Legendary edition, distinguished from later expansions. First and Second Edition have different components and setup rules.

**First Edition core box**:
The original Marvel Legendary base product, with its own card pool and setup rules. It is distinct from the Second Edition core box, a separate base game on the Revised ruleset (#215).

**Expansion**:
An additional product that adds content to the Marvel Legendary game system. An expansion's rules apply only to a setup that includes that expansion.

**Base game**:
A box that can be played on its own and carries setup rules, such as the First Edition core box, Marvel Studios Phase 1 or Legendary: Villains. A base game is an optional pick like any other box, but every setup includes at least one.

**Ruleset**:
The rules a box's cards are played under, separate from the box itself: First Edition for the core box and its Heroic expansions, Villainous for Legendary: Villains and its Villainous expansions, such as Fear Itself, and Revised for Marvel Studios' What If...? (#203) and the Marvel Legendary Second Edition core box (#215), which use the First Edition words with their own 5-player Bystanders, Warmup Round and Solo. A setup follows one ruleset, its Rule edition. Boxes of any rulesets can be included together (owner ruling, 2026-10-13, #240). With First Edition and Villainous boxes the Scheme and Mastermind decide it unless the player chooses: a Villainous Plot or Commander means Villainous, otherwise First Edition (owner decisions, #85, #88); a Revised card among them is on the First Edition side. Every other card is drawn from every included box whatever the ruleset. An expansion whose box says it can be played without a base game of its own ruleset, as Fear Itself can, follows the included base game's rules when none of its own is included (owner decision, #110).

**Rule edition**:
The ruleset a whole setup follows when its boxes follow more than one: First Edition, Villains or Revised, which the web app calls Second Edition, in the Rules choice and on its boxes (owner ruling, 2026-10-13, #240, #247). Each drawn card keeps its own ruleset's words under any edition. The player can choose it; by default a Revised base game brings Revised, and otherwise the Scheme and Mastermind decide between First Edition and Villains as above. An edition whose base game isn't included uses that base game's rules with none of its cards, and the included base game closest to it supplies the recruit stacks and starting cards.

**Villainous terms**:
The words a Villainous setup uses for the parts of a setup, one-to-one with the First Edition terms this glossary defines (Villains rulebook p.21): Ally for Hero, Adversary Group for Villain Group, Backup Adversary group for Henchman Group, Commander for Mastermind, Commander Tactic for Mastermind Tactic, Plot for Scheme, Plot Twist for Scheme Twist, Command Strike for Master Strike, Overrun for Escape, Adversary Deck for Villain Deck, Ally Deck for Hero Deck, and kidnapping for rescuing a Bystander. The code keeps the First Edition names. Bindings are not Wounds, and Madame HYDRA and New Recruits are not S.H.I.E.L.D. Officers: each is a stack of its own. HYDRA Operatives and Soldiers are the Villainous starting deck.

**Included box**:
A base game or expansion selected to contribute its cards to a particular setup. No box is mandatory, but at least one included box is a base game. Each ruleset's rules come from its first included base game in catalog order, and the Scheme and Mastermind decide which ruleset a setup follows; every other included box adds cards but no setup rules of its own.

_Avoid_: Set, when referring to a product; it can also mean a card group.

## Setup elements

**Scheme**:
A scenario card whose Setup line can change counts (Twists, Heroes, Bystanders, Wounds, Villain and Henchman Groups) and require or exclude setup components.

**Mastermind**:
The central villain selected for a game. Its "Always Leads" ability can require a particular Villain or Henchman Group in the setup, and some Masterminds print setup effects that add to setup counts.

**Setup effect**:
A change a Scheme's or Mastermind's card makes to the setup. It either sets a count (for example, 12 Bystanders in the Villain Deck) or adds to the count the setup would otherwise use (for example, one extra Hero, which makes 6 Heroes with 2–5 players and 4 in Solo). An effect can apply only at some player counts or only in Solo. A Scheme's effects apply before its Mastermind's. A Scheme that adds a Henchman Group can also say how many of its cards go in, as Scavenge Alien Weaponry's 10 Smugglers even in Solo.

**Card move**:
A setup effect that moves cards of one kind from where they come from (the Hero Deck, the Henchman Groups in the Villain Deck, or a shared stack) to the Villain Deck, the Hero Deck, beside the Scheme, each player's starting deck, or a stack set aside, for example Secret Invasion's 12 Hero cards into the Villain Deck, or the 6 Bystanders Intergalactic Kree Nega-Bomb sets aside as its Nega-Bomb Deck. Bindings come from their stack, and a Twist from those the Villain Deck doesn't use, as The Traitor sets 3 Bindings per player and a 9th Twist aside as its Betrayal Deck. Its count can depend on the player count, be per player, or have a Solo value.

**Cards beside the Scheme**:
Cards of one named group a Scheme sets beside it, whether or not that group is drawn, for example Cage Villains' 2 Cops per player or Crown Thor's Thor of the Avengers. They fill no group slot (VIL p.17). A drawn group puts only what is left of it in the Villain Deck, and a group with nothing left can't be drawn there.

_Avoid_: Card move, which moves cards of a kind from the drawn groups or a stack rather than from one named group.

**Fill-in Hero**:
One of the last Heroes, as many as there are players, listed in the Hero Deck of a Scheme where each player chooses a Hero (Sneak Attack the Heroes' Homes, `playersChooseHeroes`, #259). The Hero Deck is drawn at its normal size as if no player chose; a fill-in Hero is used only in place of an earlier listed Hero a player chose, so the finished deck is each player's own Hero, then the listed Heroes in order, skipping any a player chose.

**Setup step**:
A setup effect that changes no count but still has to be done while laying out, for example placing a token on the Scheme or splitting the Villain Deck into piles. The Setup checklist lists it as a line to tick, and a rule note cites the card or rule that prints it. Its label is a short instruction of at most 15 words in our own words, never card text. A step that would leave an extra Hero to the players names `{hero}` in its label, and the generator draws it (#242). Sneak Attack the Heroes' Homes is the one Scheme where the players choose (#259): see Fill-in Hero.

**Hero Name**:
The character a Hero card set is for (for example Jean Grey). Different Heroes can share a Hero Name, such as two versions of one character; a Hero with no other version has its own name as its Hero Name. A version of a character shares its Hero Name: Spider-Man Noir is Spider-Man. A Hero of Divided Cards whose halves show two names counts under either one, as Colossus & Wolverine counts as Wolverine (#149).

**Divided Card**:
A Civil War Hero card printed as two half-cards. It is one card for every count, so a Hero of Divided Cards is still 14 cards, and it sorts by its left half's Hero Name. In hand it counts as both halves' Hero Names and teams, so a Hero whose halves show two teams fills either team's count, one at a time (Storm & Black Panther: X-Men or Avengers, #149).

**Display name**:
The printed name a setup shows for a Hero, Villain Group, Henchman Group, Mastermind or Scheme, without a set or version suffix (a bracket stays only when printed: Spider-Man (Peter Parker)). Two boxes can print the same name, and the box label tells those cards apart; one box names each card of a kind once. It keeps the shared Hero Name.

**Reprint**:
A box's printing of another box's Hero, group, Mastermind or Scheme, as Marvel Studios Phase 1's Hulk and Loki reprint the core box's. A reprint is the same card (roadmap decision D5, #34): a setup with either box can draw it, it is drawn at most once when both are included, and it names both boxes, since either box's card will do. A new version with different setup data is not a reprint; it takes a distinguishing display name.

**Hero constraint**:
A Scheme's rule on which Heroes the Hero Deck holds: a required Hero, which fills a Hero slot like a required group; at least or exactly some number of Heroes of a team, with a Hero Name, or with a word in their Hero Names (Fall of the Hulks: exactly 2 with "Hulk"); a team split, exactly some number of Heroes of each of one or more different teams the draw picks (Avengers vs. X-Men: 3 of one team and 3 of another; House of M: 4 of one team); or no two Heroes with the same Hero Name. The Heroes are drawn within these rules, which the Scheme's own box's Heroes can always meet (#138).

**Hero outside the Hero Deck**:
A Hero a Scheme draws in addition to the Hero Deck, which sends all its cards to the Villain Deck, beside the Scheme, or a stack set aside. The draw can name the Hero, or limit it to a Hero Name, a list of Hero Names, a word in the Hero Name ("Hulk" for Shoot Hulk into Space) or a team.

_Avoid_: Extra Hero, which is the setup effect that adds a Hero to the Hero Deck.

**Henchman Group outside the Villain Deck**:
A Henchman Group a Scheme draws in addition to the Villain Deck's, from the included groups the setup doesn't already use, which sends some of its cards to the Hero Deck; the rest of the group stays out of the game.

_Avoid_: Extra Henchman Group, which is the setup effect that adds a Henchman Group to the Villain Deck.

**Other Mastermind**:
A Mastermind a Scheme draws besides the setup's own, from the other included Masterminds. It is set aside whole until the Scheme brings it into play, or only its Tactics go into the Villain Deck, where they play as Villains with no abilities. Its Always Leads group is not added.

_Avoid_: Second Mastermind as a setup term; a rule note can use the Scheme's own words.

**Set-aside Villains**:
The Villains of an extra Villain Group that a Mastermind sets aside instead of shuffling into the Villain Deck, as Kang, Quantum Conqueror's Timeline Variants. They leave the Villain Deck total and show under Set aside; the group's Ambush Schemes (cards that aren't Villains) stay in the Villain Deck.

**Mastermind joins later**:
A Scheme whose card has no Mastermind at setup and adds a random one mid-game, as Second Edition's Enshrouded Identity does when the Bodyguards are gone (Card, #245). The Mastermind is still drawn, but its Always Leads groups and setup effects are no part of the setup: the Villain Deck has only random groups. The checklist hides it behind a "Reveal Mastermind" button; revealing shows it with its box, its Always Leads groups (marked as not in this Villain Deck) and its Start of Game effects (`mastermindReveal` in the response). Until then the glossary leaves out the terms only it and those groups bring.

**Always Leads group**:
The Villain Group or Henchman Group required by a selected Mastermind's "Always Leads" ability. A Mastermind whose ability allows any group, as Ego's does, has no Always Leads group. It fills one of the player-count group slots rather than being added on top. First Edition Solo ignores this ability. Some Masterminds lead one of several groups instead, as Sinister Six 2099 leads Alchemax Enforcers or False Aesir of Alchemax: a group already in the setup serves, otherwise one is drawn at random. A few Masterminds also always lead one of several groups besides their Always Leads group, as Deathbird leads the Shi'ar Imperial Guard and a Shi'ar Henchman Group; that second group fills a slot the same way. Its choices can include another box's groups when that box is included, as Bastion, Fused Sentinel leads any Sentinel Henchman Group.

**Part in use**:
A part of the game that a drawn card or the setup's rules use, so the setup lays it out; a part nothing uses is left out, and the checklist never mentions it: it tells the player only what to add (owner decisions, #87, #148). So far the parts are the shared stacks other than Bystanders, X-Men's Horrors, and the Shard supply. A card uses a stack when its text takes cards or tokens from it, as Hulk gives Wounds and Gamora gains Shards, or when its Setup line sizes it, as The Legacy Virus sets the Wound stack or Unite the Shards fills the Shard supply; the rules use the stacks players recruit from. Special Bystanders, which every setup shuffles in with the other Bystanders, bring the parts they use too, so Civil War's Aspiring Hero, which gains a Sidekick when rescued, lays the Sidekick stack out whenever Civil War is included (#125). A Hero, group or Mastermind that uses a part no included box supplies is not drawn; a Scheme and the cards it requires are, and the part is laid out from the base game that has it (#138).

**Stand-in**:
A part a setup lays out in place of one no included box supplies, as an expansion's rules allow when it is played without its own ruleset's base game: with the core box and Fear Itself alone, Wounds stand in for Bindings and S.H.I.E.L.D. Officers for Madame HYDRA (Fear Itself insert, owner decision #110). Legendary: Villains also lets its Bindings stand in for Wounds, so a card that uses Wounds is drawable with Villains and no Wounds box (owner ruling, #141, #241). The checklist names a stand-in with both parts, stand-in first (Bindings/Wounds, Wounds/Bindings, S.H.I.E.L.D. Officers/Madame HYDRA), so the player can use whichever cards they own (owner ruling, #141, #258); when a ticked box supplies the real part, the plain name stays.

**Shard supply**:
The shared pool of Shard tokens Guardians of the Galaxy adds (18 double-sided tokens, GG p.2), which players, Villains and Masterminds gain from. It is a part in use like a stack: laid out only when a drawn card gains or spends Shards, holding all the Shard tokens the included boxes supply (the tokens' two sides cover even Unite the Shards' 30 Shards, owner decision #107).

**Required group**:
A group a Scheme names as required (for example, Skrulls). Like an Always Leads group, it fills a group slot. A Scheme can say how many of a required Henchman Group's cards go in, as Alien Brood Encounters adds all 10 Brood even in Solo. A Scheme can instead require exactly one of several groups and leave the others out, as S.H.I.E.L.D. vs. HYDRA War takes A.I.M., Hydra Offshoot or Hydra Elite but not both: the drawn Mastermind's Always Leads group when it is one of them, otherwise one drawn (#172).

**Horrors**:
X-Men's 20 Horror cards, which make a game harder (XM p.2). A part in use: the setup lays them out only when a drawn card plays them, as Horror of Horrors does. A Mastermind's Epic side also brings them in, which the setup lays out when it plays the Epic side.

**Epic Mastermind**:
A Mastermind's other card face, with the same Tactics (XM p.2). It is an option (`epic=true`, "Epic Masterminds" in the web app): with it on, a drawn Mastermind that has an Epic side is played on that side, under its printed Epic title, with the Epic side's own Setup line in place of the normal side's and the parts its text uses beside the normal side's; without it, or when the Epic side uses a part no included box supplies, the normal side is drawn and its card offers the Epic side as a step. The Epic side keeps the same Always Leads unless its card says otherwise (#185).

**Villain Group**:
A named set of 8 Villain cards selected as one setup component.

**Henchman Group**:
A named set of 10 identical Henchman cards selected as one setup component.

**Difficulty rating**:
How likely the players are to lose a drawn setup, 1 (easiest) to 5, with a Band name and up to three reasons. It is computed from the whole setup, and a request may name a **Difficulty target** (1 to 5) that only steers the draw among the options the rules already allow: it never relaxes a rule or drops or redraws a Scheme (#267, #329). The first version (#264) reads the Hero Deck only: its cost curve and its team and class mix, weighted by copies. The rating is relative to the player count (#334): the opposition's load is read against a scale moved up by the load that player count's own Villain Deck adds over 2 players' (more Villain Groups and Henchman cards; fewer in Solo), so a 5-player setup rates against other 5-player setups, and the 2-player scale is the calibrated one.

**Difficulty target**:
The 1 to 5 rating a request asks for with `difficulty=`. A target is not a rule: the setup is drawn plainly, then its open picks (the Hero Deck Heroes no card requires and the groups drawn into open slots) are swapped among legal options until its real rating is the target, or as close as the swaps found (#329). The Scheme and Mastermind stay as drawn. The response carries the target, the real rating, whether it was reached and, when it wasn't, a note naming the closest band found.

**Band**:
One of the five named steps of the Difficulty rating: Sidekick, Street-Level, Heavy Hitter, Cosmic Threat and Secret Wars. A display name only; the rating number is what the code uses.

**Complexity**:
How much there is to learn and remember in a drawn setup, 1 (simplest) to 5, with a Band name (Origin Story, Team-Up, Crossover, Multiverse, Event Series) and up to three reasons; independent of Difficulty (#270). It reads the expansion keywords and the stacks beyond Wounds and Officers the drawn cards need, mixed rulesets and stand-ins, the boxes drawn cards come from and the Scheme and Mastermind setup steps, never the difficulty tags. A request may name a **Complexity target** with `complexity=`; like the Difficulty target it only repairs the open picks among legal options, and with both targets the repair minimises the sum of the two distances.

**Player count**:
The number of players in a game; the First Edition core rules use it to determine setup quantities. This project targets one to five players.

**First Edition Solo mode**:
The one-player mode defined in the First Edition core rulebook: three Heroes, one Villain Group, three cards from one Henchman Group, one Bystander, one Master Strike, and the Scheme's normal Twists. It ignores Always Leads and excludes *Super Hero Civil War* and *Negative Zone Prison Breakout*. A Scheme's own Setup line overrides these Solo values.

**Mixed setup**:
A setup whose drawn cards come from both rulesets, Heroic and Villainous. It draws from shared pools for every card type and shuffles all Bystanders together (Villains rulebook pp.20-21). With a Villainous Plot or Commander it follows the Villains rules and the rest of the combined setup: the recruit stacks of every included base game, and a choice of S.H.I.E.L.D. or HYDRA starting decks when both base games are included. Otherwise it follows the First Edition rules, and its Villainous cards bring only the parts they use. Each card keeps its own side's name (a Plot, a Mastermind); a part holding both kinds is named by both words.

**Villainous Solo mode**:
The one-player mode in the Villains rulebook: three Allies, one Adversary Group, three cards from one Backup Adversary group, one Bystander, five Command Strikes, and the Plot's normal Twists. It ignores Always Leads; each Plot Twist also sends a cheap Lair Ally under the Ally Deck, and each Command Strike plays another card. The rulebook titles it Advanced Solo Mode, but it is Villains' only one-player mode.

**Advanced Solo**:
A solo-play variant from later products and community material; not part of the First Edition core box.

## Rule precedence

**Rule precedence**:
Printed card text overrides the rulebook: a Scheme overrides a Mastermind's Always Leads and the Solo setup. Otherwise the base game's rules apply. Rules from an expansion apply only when that expansion is an included box.

## Game setup

**Game setup**:
The combination of game elements selected before play begins. Its identity is the Scheme, the Mastermind, the set of Heroes, the set of Villain Groups, and the set of Henchman Groups; shuffles and choices among identical cards do not create a different setup.

**Legal setup**:
A game setup that satisfies all applicable official setup rules; legality does not imply a particular difficulty or balance.

**Random setup**:
A complete legal setup selected without player-selected card preferences; only official setup rules constrain the selection.

**Table draw**:
How a random setup is selected, mirroring a normal game at the table: draw the Scheme from every included Scheme its card allows at the player count, then the Mastermind from the included ones the Scheme doesn't exclude, then add the groups the Scheme and Mastermind require, then draw the remaining Villain and Henchman Groups from what is left, then any Henchman Groups outside the Villain Deck, then draw the Heroes, then any Heroes outside the Hero Deck. Each draw is equally likely among the remaining options that still leave a legal setup. Nothing is checked per draw: every requirement a box's cards make is met inside that box, or allowed from another box by its data (owner decision, #138).

**Scheme-first random selection**:
The table draw's first step: the Scheme comes first, from every included Scheme its card allows at the player count, and everything else follows from it. A Scheme rules a Mastermind out only when its card says so, recorded in its box file as an excluded Mastermind (owner decision, #138). A Scheme that changes the number of city spaces also rules out a Mastermind whose card is not played with one, as Ego, the Living Planet's insert says, whichever box either is in (#192).

**Required card from another box**:
A card a Scheme requires that is in a box the setup doesn't include, as The Kree-Skrull War's core box Skrulls. The setup still uses it, since the player owns it, and the checklist says the Scheme requires it from that box; when the card names a substitute, an included card takes its place instead (owner decision, #138). Heroes a Scheme's Hero rules need that no included box has, as a second team of three for Avengers vs. X-Men with Marvel Studios Phase 1 and Civil War alone, are such cards too (#147). A card the Scheme names, as a Hero with a given Hero Name or a named group, comes from the included boxes whenever one of them holds a match, a reprint included, and from another box only when none does; basic parts such as Wounds or Sidekicks come from the first loaded box that has them (owner, #141, #150).

**Setup checklist**:
What a generated setup gives the player to lay out the game: the chosen components; the Villain Deck and Hero Deck with per-component counts and totals (the Hero Deck's including any Henchmen from a Henchman Group outside the Villain Deck); the Twists and any cards of a group beside the Scheme; any cards a Scheme sets aside; any Heroes outside the Hero Deck and where their cards go; the Bystanders and each other shared stack that is a part in use (Wounds, S.H.I.E.L.D. Officers, Bindings, Madame HYDRA, New Recruits, Sidekicks or the Shard supply), each holding what the included boxes supply unless the Scheme sets its size; each player's starting deck; any setup steps; the rule notes; and the glossary terms its components use and those a box attaches to a stack the setup lays out (`stackTerms`: Civil War's Grievous Wound with the Wound Stack and Sidekick with the Sidekick Stack, Weapon X's Enraging Wound, #127). When the setup includes more than one box, each drawn card names the box it comes from.

**Rule note**:
One short line naming a rule that changed a setup, with its citation (for example "R p.6") and a link to the source when one is published. Never card or rulebook text.

**Glossary term**:
A Hero team, Hero class or keyword that a setup component uses (for example Avengers, Covert or Ambush), with a summary of at most 40 words written in our own words and a citation to the rulebook page that defines it. Never rulebook or card text.

_Avoid_: Keyword, for teams and classes; a keyword is one kind of glossary term.

**Box description**:
A box's short about text, shown from the info button beside it in the box picker with the year it was first published: an original summary of at most 50 words, in our own words, of what the box is and adds. Never the box's back copy, rulebook or store text.

**Special cards**:
The printed names of the special cards a box shuffles into a shared stack, such as Dimensions' Special Bystanders. The checklist lists them, by box, from an (i) button beside the stack's line.

**Setup code**:
A short string that reloads one drawn setup (#335, #340), shown under the drawn cards with buttons to copy it or a link (`?code=`) that opens it. It names the cards, not a seed: the player count, then the Scheme, the Masterminds, the Villain Groups, the Henchman Groups and the Heroes as short card numbers from a fixed, append-only order, then a short box data version and, only when needed, Epic Masterminds, the chosen rule edition and the included boxes. The boxes come from the cards unless a ticked box with no drawn card changes the setup. Reloading searches for a draw that gives the code's cards, so a code keeps working while its cards can still be drawn together, even after other box data changes; when they can't, it says the data has changed instead of showing another setup. `GET /api/setup/{code}` returns the setup with its ratings, player count and box ids.

**Saved setup**:
A setup the player kept on this device (#335): its setup code with a name, an optional note and the date it was saved, held in the browser's storage and listed under Load a setup. Loading one reloads its code; no cards are stored. Saving the same code again replaces its name and note.

**No eligible Scheme**:
The result when no Scheme in the included boxes is allowed at the player count, or no Mastermind is included. It is a result, not an error.

## Rules authority

**Attributed designer or publisher ruling**:
A ruling directly attributed to the game's designer or an Upper Deck rules representative; an unattributed community interpretation is not authoritative.
