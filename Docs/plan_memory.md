# LegendaryPicker plan memory

**Snapshot date:** 2026-09-28
**Phase:** Design confirmed; implementation is tracked as GitHub issues under the "Legendary Picker v1" parent issue.

This is a handoff snapshot. `Docs/Plan.md` holds the decisions, the verified First Edition facts and their sources; `CONTEXT.md` is the domain glossary. Keep facts there, not here.

## Where things stand

- Repository: [RyanGano/LegendaryPicker](https://github.com/RyanGano/LegendaryPicker), branch `main`.
- `LegendaryPickerService` loads the core box catalog and setup rules from `Data/Boxes/core.json`, and serves `/api/health` (GET and HEAD, for the UptimeRobot keep-warm monitor, #31) and the rate-limited `GET /api/setup?players=1..5` (issue #4), which returns a `Setup/SetupGenerator` draw (issue #3). `LegendaryPickerApp` pings `/api/health` on load, lets the player pick a count (#5) and renders the draw as the Setup checklist, with counts, totals, cited Rule notes and per-line ticks that reset on a new draw (#6). Players choose which boxes to include (#8): the API takes `boxes=` and lists the boxes at `/api/boxes`, and with more than one box each rule note, glossary term and drawn card names its box. Display names are unique per kind across all boxes, enforced at load (#76). Base games are optional picks like any other box (#71, owner decision D1 in #34, 2026-09-29): a setup needs at least one base game and the core box is never mandatory. Every box file names its `ruleset` at the top level (`firstEdition`, or `villainous` for Legendary: Villains); several base games of one ruleset follow the first in catalog order. Heroic and Villainous boxes can be included together (#73): the Scheme and Mastermind decide the rules (owner decision D-mixed, #85, refined in #88, 2026-09-29): Villains rules when the Plot or Commander is Villainous, First Edition otherwise. Every other card is drawn from every included box whatever the pair, so nothing is locked out. A setup with cards of both rulesets is mixed: shared pools and all Bystanders together (VIL pp.20-21); under the Villains rules also every base game's recruit stacks and a choice of S.H.I.E.L.D. or HYDRA starting decks, while under the First Edition rules its Villainous cards bring only the parts they use (D-uses). The pair is drawn first, so every result is consistent; the result's `rulesReason` names the Plot or Commander that set the rules, or says there is none. The owner's #92 answers are recorded as source key D-readings in `Docs/Plan.md`. Box files are `schemaVersion` 5. Legendary: Villains is the second base game (#72, `Data/Boxes/villains.json`, source VIL, the Villains rulebook): 15 Allies, 7 Adversary Groups, 4 Backup Adversary groups, 4 Commanders and all 8 Plots. Cage Villains in Power-Suppressing Cells and Crown Thor King of Asgard (#84) set cards of a group beside the Plot through a Scheme's `setup.cardsBeside`, read from the Plots' card images; the cards fill no group slot (VIL p.17), and a drawn group puts only what is left of it in the Adversary Deck. Its setup table matches the core box's, with a 6th Ally at 5 players (`setup.extraHeroes`); its Solo (the rulebook's Advanced Solo Mode, Villains' only one-player mode) uses 5 Command Strikes and two play rules (`solo.playRules`, which replaced the core box's `twistKosHeroCostingAtMost`). Its stacks are Bindings, Madame HYDRA and New Recruits, stacks of their own; it follows the setup page's 12 Madame HYDRA and 41 Bystanders over the contents list's 15 and 42. A Villainous setup's notes and checklist use the Villains rulebook's words (Plot, Commander, Ally, Adversary Deck, …). The web app lists base games above expansions, ticks the core box on a first visit, remembers every ticked box in `localStorage`, and disables Generate with a hint when no base game is ticked. Dark City is the first real expansion (#40, `Data/Boxes/dark-city.json`, source DC): 17 Heroes, 6 Villain Groups, 2 Henchman Groups, 5 Masterminds, 11 Special Bystanders and all 8 Schemes. A Scheme can set how many cards of each Henchman Group go in the Villain Deck (`setup.henchmanCards`, #68), which overrides Solo's 3 under D2, so Organized Crime Wave puts all 10 Maggia Goons in a Solo game. Fantastic Four follows (#41, `Data/Boxes/fantastic-four.json`, source FF): 5 Heroes, 2 Villain Groups, 2 Masterminds and all 4 Schemes, each changing only its Twist count; it has no Henchman Groups. Paint the Town Red follows (#42, `Data/Boxes/paint-the-town-red.json`, source PTTR): 5 Heroes, 2 Villain Groups, 2 Masterminds and all 4 Schemes. Invade the Daily Bugle News HQ draws a Henchman Group outside the Villain Deck and puts 6 of its Henchmen in the Hero Deck (`setup.outsideHenchmen`, #77); a Scheme is dropped when no Henchman Group is left for it. Generator capabilities are still tested with made-up fixture expansions. Shared stacks (Bystanders, Wounds, Officers, and Sidekicks when a box has them) are summed over the included boxes' `components` (#35). Setup effects can add to counts as well as set them (extra Heroes, Villain Groups, Henchman Groups and Villain Deck Bystanders), per player count or only in Solo, and a Mastermind can carry them too (#36). Schemes can move cards between stacks and decks during setup (`setup.moves`: Hero cards, Henchmen, Bystanders, Wounds, Officers or Sidekicks into the Villain Deck, the Hero Deck, beside the Scheme or each starting deck), which replaced `heroCardsInVillainDeck` (#37) and moved box files to `schemaVersion` 3. Schemes can constrain the Hero Deck (required Heroes, at least or exactly N Heroes of a team or Hero Name, no two Heroes with the same Hero Name) and draw Heroes outside it into the Villain Deck, beside the Scheme or a stack set aside (`requiredHeroes`, `heroCounts`, `distinctHeroNames`, `outsideHeroes`); a Hero can carry a `heroName` (#38). Schemes and Masterminds can list setup steps that change no counts (`setup.steps`, each a short label in our own words with a source), which the checklist shows as lines to tick with a rule note each (#39). The docs now date the First Edition core box to November 2012 (#34 D6). Each setup also carries the glossary terms its components use: teams, classes and keywords with short original summaries and rulebook citations (#28); the UI for them is #29.
- GitHub Pages deploys the frontend from `main`: https://ryangano.github.io/LegendaryPicker/.
- The API is hosted on Azure App Service Free F1, Linux, West US 2, $0 a month (user decision, 2026-09-27). The web app is the one named by the `AZURE_WEBAPP_NAME` repository variable; the resource names and hostname are kept out of the repo. `.github/workflows/deploy-api.yml` deploys it from `main` through OIDC (the Entra app identified by the `AZURE_CLIENT_ID` repository variable, trusted for `refs/heads/main` only); the Pages build points at it through the `VITE_API_BASE_URL` repository variable (#7). Any other Azure resource needs explicit authorization.

## Resolved in the 2026-09-27 session

- The whole core-box catalog is confirmed. An earlier note wrongly listed Sentinel and Hand Ninjas as Villain Groups; they are Henchman Groups.
- Solo uses 1 Master Strike, not 5.
- A Scheme's setup overrides the Solo setup (designer ruling for *Secret Invasion*; the user accepted applying it to Bank Robbery, Killbots and Legacy Virus).
- Always Leads groups and Scheme-required groups fill slots rather than adding groups; the user accepted the extension to Skrulls.
- Generation is a table draw (Scheme, Mastermind, required groups, remaining groups, Heroes), replacing the earlier "uniform over distinct setups" wording.
- Unsourced conflicts fall back to the base Legendary rules; expansion rules apply only when that box is included.
- The planning "cases" are GitHub issues; each issue lists the fixed-result test cases it must pass.
- Owner decision D-heroic (2026-10-04, #110): Fear Itself works without Legendary: Villains. With a Heroic base game and Fear Itself but no Villainous base game, every pair follows the First Edition rules, and Fear Itself's `otherRuleset.standIns` (FI p.2) replace parts no included box supplies: Wounds for Bindings (the player may use Bindings), S.H.I.E.L.D. Officers for Madame HYDRA, and +1 Recruit for a New Recruit gain.
